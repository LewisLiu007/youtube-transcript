# 人类驯服可控核聚变还有多少路程？

## 嘉宾
杨昭 - 中国可控核聚变创业公司能量奇点的创始人

## 主要话题
- 核裂变与核聚变的基本原理与区别
- 托卡马克装置与磁约束技术路线
- 低温超导vs高温超导材料的优劣对比
- 能量增益(Q值)与三乘基物理参数
- 可控核聚变的商业化前景与成本路径

## 核心观点
1. 核聚变是通过轻原子核融合释放能量，与原子弹原理（裂变）相反，氢弹采用聚变原理但不可控
2. 托卡马克通过甜甜圈形磁场约束等离子体，是目前研究最广泛且参数最高的磁约束技术
3. 高温超导相比低温超导临界磁场强度高一倍以上，可将装置体积和造价缩小两个数量级
4. 能量增益(Q值)由三乘基决定，需达到10^21数量级才能实现商业化发电，目前全球最高Q值约1.5
5. 低温超导装置虽可长时间运行但成本极高（电成本为火电100倍以上），ITER项目耗资250亿欧元历时30年
6. 高温超导托卡马克提供了将聚变电成本降至与火电相当甚至更低的可行路径

## 关键信息
- 全球仅三台全低温超导托卡马克：中国EAST、韩国KSTAR、日本JT-60SA
- 磁约束托卡马克定标律：三乘基正比于磁场3.5次方×装置线性尺寸2.5次方
- 商业聚变电站设计目标：Q值在5-30之间
- 高温超导材料在2015-2018年实现工业量产
- 磁场强度提升一倍可将线性尺寸缩小至原来30%，成本降至原来2%左右
- 能量奇点总部位于上海临港，与特斯拉工厂相邻
