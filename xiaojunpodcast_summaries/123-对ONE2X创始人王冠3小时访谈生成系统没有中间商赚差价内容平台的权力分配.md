# 对ONE2X创始人王冠3小时访谈：生成系统、没有中间商赚差价、内容平台的权力分配

## 嘉宾
**王冠** - ONE2X联合创始人兼CEO，前Moonshot AI模型产品负责人，AI产品经理

## 主要话题
- AI产品经理的价值在AI时代如何被放大
- 大模型与传统AI算法的本质区别（结构化vs非结构化数据）
- AI应用创业的正确方向选择与避坑
- 内容平台的权力分配与去中间化
- AI生成系统与推荐系统的核心差异

## 核心观点
1. **产品经理价值被放大**：在System 1（模型能力设计）和System 2（价值释放）两个层面，产品经理都发挥决定性作用，而非被技术取代
2. **结构化vs非结构化数据**：大模型的革命在于处理非结构化数据，能表达连续的世界，而非离散的点
3. **避免踩坑**：AI创业应理解大模型公司的迭代方向，避免做被迭代覆盖的功能层
4. **没有中间商赚差价**：当前互联网平台都是中间商，AI时代应重新定义内容生产、分配、供给的方式
5. **工作室vs公司**：强调以"超级个体"和"AI全栈工程师"组织，追求产品质量而非纯商业目标

## 关键信息
- 王冠AI从业已满10年，经历大数据、CV深度学习、预训练大模型三个阶段
- 曾在百度、矿视、兰州科技等公司工作，见证AI产业发展
- 创业中三次精准踩到OpenAI的迭代路径（文本生成→代码生成→插件系统）
- ONE2X定位为AI时代的产品工作室，推出AI视频生成器MyDio
- 核心观点：产品经理应理解模型的System 1设计和System 2的价值释放机制
