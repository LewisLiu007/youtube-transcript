# 126. 和红杉郑庆生聊：经济史的流量革命、人类行为模式的不可预期，与创始人性格

## 嘉宾
**郑庆生** - 红杉中国合伙人，主要关注科技和早期投资，近年聚焦AI、大模型、Agent等领域

## 主要话题
- 用"流量"作为经济史的核心指标来理解人类历史发展
- 中国互联网20年的三轮技术浪潮（PC互联网、移动互联网、AI）与创业阶段划分
- Web 2.0产品创新与人类行为模式的演变
- 创始人性格与公司产品气质的匹配度
- 投资人的职业生涯演变与多元工作背景的价值

## 核心观点
- **流量视角**：人类经济史本质上是流量、移动和连接的历史，城镇和互联网产品都是此逻辑的体现
- **产品创新驱动**：Web 2.0时代通过UGC内容改变了人类认知形态，AI时代也会引发新的不可预期的行为模式
- **创始人与产品合一**：优秀创始人的内心世界会投射到产品中，CEO需要成为组织和制度的人格化象征
- **工作积累的复利**：审计、咨询等看似无关的工作经历在投资决策中产生意外价值
- **长期视角**：从2005年入行投资至今20年，见证了中国互联网从门户到社交再到AI的完整演进

## 关键信息
- 郑庆生1984年开始学编程，1996年第一次上网，见证了中国互联网从零到一的全过程
- 曾在德勤做审计、IBM做咨询、盛大做投资，2005年正式转向投资行业
- 在盛大期间接触到豆瓣（2005年）和大众点评，这两家公司让他认识到Web 2.0的产品创新意义
- 2007年加入执行资本，后来加入知信资本，最终加入红杉中国
- 红杉中国的早期投资比例已占总项目数的50%，2018年后尤为突出
