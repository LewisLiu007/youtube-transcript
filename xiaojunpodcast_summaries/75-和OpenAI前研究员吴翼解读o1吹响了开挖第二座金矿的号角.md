# 和OpenAI前研究员吴翼解读o1：吹响了开挖第二座金矿的号角

## 嘉宾
**吴翼** - OpenAI前研究员（2019年2月-2020年7月）、清华大学交叉信息研究院助理教授、边塞科技创始人

## 主要话题
- O1模型的技术突破与推理能力提升
- 强化学习范式在大模型中的应用
- AGI发展路线从预训练到后训练的转变
- 强化学习的三大关键要素：奖励模型、搜索探索、提示工程
- O1 Preview版本的实际体验与完整版期待

## 核心观点
- **范式转变而非转弯**：AGI不是改变路线，而是从预训练时代进入以强化学习驱动的后训练阶段，类似从第一座金矿转向第二座金矿
- **推理成本的技术突破**：O1在10秒内完成数千token的推理链，涉及搜索、回溯等复杂过程，技术难度极高
- **多维度的复杂系统**：强化学习不仅需要优秀的奖励模型，还需要高效的探索算法和合适的任务设计，三个要素缺一不可
- **Scaling Law的未知性**：强化学习是否遵循Scaling Law仍未确定，需要在算力、数据、算法上同时突破
- **产品化的关键**：O1的真正价值不只在难题能力，更在于能否让普通用户用更短的Prompt完成复杂任务

## 关键信息
- **时间背景**：吴翼2019年2月至2020年7月在OpenAI工作，期间见证了O1前身项目（代号草莓Strawberry、Q*）的内部讨论
- **技术细节**：O1的推理长度超出预期，会产生几千token的推理链，体现了真正的搜索和探索过程
- **学术背景**：吴翼2016年从UC Berkeley开始研究深度强化学习，首篇论文《Value Function Networks》获NIPS16最佳论文，师承Peter Abbeel等强化学习先驱
- **发展历程**：强化学习算法从DQN→AlphaGo→PPO演进，PPO成为OpenAI当前主要使用的算法
- **阶段判断**：Preview版本可能处于后训练的GPT-3时刻，完整版本发布后才能判断是否达到ChatGPT时刻的产品化突破
