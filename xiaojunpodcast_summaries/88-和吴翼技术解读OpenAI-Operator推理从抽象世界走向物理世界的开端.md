# 88. 和吴翼技术解读OpenAI Operator：推理从抽象世界走向物理世界的开端

## 嘉宾
**吴亦** - 清华大学交叉信息研究院助理教授，强化学习研究方向专家，曾在加州大学伯克利分校获博士学位，2019-2020年在OpenAI工作

## 主要话题
- OpenAI Operator产品的技术架构与创新意义
- 推理模型从O1/O3向多模态Agent的演进
- Computer Using Agent（CUA）概念的本质与应用
- 强化学习在Agent训练中的关键作用
- 2025年"智能体元年"的技术基础与前景

## 核心观点
1. **闭环交互是关键突破**：Operator实现了从开环系统（O1/O3）到闭环控制系统的转变，具备观测-动作-反馈的循环能力
2. **多模态赋予泛化性**：相比O1/O3的深度推理，Operator通过多模态输入获得更强的泛化能力，能处理多样化任务
3. **技术路线已然清晰**：好的基础模型+高质量数据+高效强化学习训练系统是三大核心要素
4. **从失败到成功需时10年**：OpenAI 2016年Web Agent失败因缺基础模型，2025年终于成功，技术条件此时完全就位
5. **模型深度与广度的平衡**：Operator相比O3思维链较短，更像是多模态世界的O1版本，仍有优化空间

## 关键信息
- OpenAI发布Operator时间：2025年1月24日凌晨
- CUA（Computer Using Agent）首先由Anthropic提出
- OpenAI 2016年Web Agent项目失败，当时裁减约30人
- Operator使用新的多模态基础模型与专门训练数据
- 强化学习训练系统需支持与网页/操作系统的实时交互
- 国内团队复刻Operator难度不如追赶GPT-4O/O1/O3那么远，但需完整的强化学习训练体系
