# 开源一段论文探索之旅：模型范式、Infra和数据、语言、多模态的完整变迁史

## 嘉宾
**谢清池** - 美团光年之外产品负责人，非技术出身但自学计算机基础，曾在豆瓣从事产品工作，2022年后系统性学习AI基础知识。

## 主要话题
- 如何高效读AI论文的方法论和工具应用
- 深度学习发展的四大驱动要素（芯片、Infra、数据、模型结构）
- GPU演进史与GPU编程的发展
- 模型范式的变迁过程
- AI学习资源推荐（视频课程、书籍、工具）

## 核心观点
- 读论文的关键是理解论文解决的**核心问题**及其历史背景，而非单点知识
- 现代产品经理需要理解AI技术边界的变化，这是推动产品创新的底层能力
- 应充分利用AI工具（如ChatGPT、Claude、沉浸式翻译）来学习AI，降低英文和数学障碍
- 深度学习的发展遵循范式变迁规律：旧范式遇到危机或新范式突然崛起
- 论文阅读应从三个维度理解：历史脉络、范式变迁、人物贡献
