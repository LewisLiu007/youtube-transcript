## 3. 核电站风险与干式贮存
- 工作机理：核反应堆即便紧急停堆，仍需外部供电维持冷却水循环；乏燃料池（Spent Fuel Pool）中的燃料棒在数年内释放衰变热，若失去冷却水，会沸腾、暴露并引发包壳起火。
- 事故链：长时间电网故障 → 冷却失效 → 氢氧爆炸/燃料池干涸 → 核素释放 → 人员无法接近处置 → 失控扩散。
- 干式贮存（Dry Cask Storage）：将足够“冷却”的乏燃料转移至密封容器，无需水循环，千年尺度的安全封存方式，显著降低系统性风险。
- 建议（社会层面）：
  - 立即推进对符合条件的乏燃料全面干式贮存转移。
  - 明确监管与强制标准：避免因市场竞争与短期成本而长期拖延。
